# Rat Park

An early, static website concept for a tattoo artist. The page uses the artist's supplied artwork and is designed for GitHub Pages. Open `index.html` directly or run `python3 -m http.server` to preview locally.

## Before using it as a booking site

- Add the artist's confirmed contact address or Instagram handle and city. The booking section is intentionally marked as a preview until then.
- Review all first-person copy with the artist.
- Add the PDF artwork when it is supplied; no Rat Park PDF was attached to the request.
- Add legal notice and privacy details if the site becomes a live business site.

The Rat Park paragraph treats the experiment as inspiration, without claiming that environment alone explains addiction. Background: [original 1978 study](https://pubmed.ncbi.nlm.nih.gov/98787/) and [replication review](https://psycharchives.org/en/item/e9061d38-2a89-4fc3-97a0-b469e27eaf93).
